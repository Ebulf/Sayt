## 4. Tradeoffs

The five-device MTS illustration uses two icon rows, adding 56px to that desktop grid row and leaving some additional whitespace in adjacent cards. This is accepted to preserve readable device names and distinct glyphs. The mobile layout stacks cards and avoids spreading that extra height to neighboring cards. A later density adjustment is optional rather than a release blocker.

Operator identities retain their own colors within the restrained black, white and carmine page. The contrast is deliberate and preserves quick recognition without recoloring the main interface for each operator.
