# Заявки в закрытой Telegram-группе

Группа «Заявки — Тарифы от Кристины» принадлежит владельцу Telegram-аккаунта. Новые заявки сохраняются во внутренней Google Таблице, затем отправляются ботом в подключённую закрытую группу. Для сотрудников Google-аккаунт не требуется.

Владелец подключает группу командой `/connect@EbulfTarifyRequestsBot`. Бот сверяет отправителя с закрытым параметром `TELEGRAM_CHAT_ID`, проверяет, что группа частная, и сохраняет `TELEGRAM_GROUP_ID` в Script Properties. В публичных файлах ключа бота и идентификаторов сотрудников нет.

Взять в работу → Связались → Завершена. Первый сотрудник становится ответственным. Менять следующие статусы может он или владелец. Бот проверяет текущее участие человека в группе, исходное сообщение и допустимую последовательность статусов. Завершённая карточка остаётся в истории без кнопок. Изменения сохраняются во внутреннем хранилище.

Бот опрашивает события раз в минуту, поэтому обновление кнопки может занимать около минуты. Заявка подтверждается клиенту после сохранения; если Telegram недоступен, отправка повторяется каждые пять минут. После неопределённого сетевого сбоя Telegram возможна повторная карточка: Bot API не предоставляет ключ идемпотентности для sendMessage. Статусы привязаны к сохранённому сообщению.

Приглашайте только сотрудников: все участники группы видят новые контакты клиентов. Обычный /start не даёт доступ. При передаче проекта заказчику передаются группа, бот, Google-хранилище и проект сайта. После смены владельца нужно обновить TELEGRAM_CHAT_ID и создать триггеры под его аккаунтом.

Проверки: node scripts/build-request-backend.cjs; node tests/group.cjs; node tests/telegram-full.cjs.
