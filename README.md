# Тарифы от Кристины
Основной проект и опубликованный сайт: https://ebulf.github.io/Sayt/

Откройте `index.html` или запустите `npm start` и перейдите на http://127.0.0.1:8765. Рабочие файлы находятся в корне: `index.html`, `style.css`, `app.js`. Данные 64 тарифов — `assets/content.js`; исходные карточки — `assets/materials/`.

`npm install` устанавливает инструменты проверок. `npm test` проверяет все условия и функции. `npm run test:browser` проверяет Chrome на пяти ширинах, рамки выбора, фокус и быстрые переключения. `npm run test:reduced` повторяет проверку при уменьшенном движении. Результаты находятся в `reports/`.

Публикация GitHub Pages идёт из корня ветки `main`. Перед `git push` выполните проверки. Решения дизайна, исследование и финальный просмотр сохранены в `docs/`.

Форма заявки работает: данные сохраняются в закрытой Google Таблице, уведомления поступают в Telegram. Описание: `docs/REQUESTS.md`. `npm run test:requests` проверяет отправку, ошибки и защиту данных. Реальные контактные адреса ещё не предоставлены. Социальные кнопки сообщают об этом. Оплата на сайте не подключена. Цены, регион и доступность требуют подтверждения.

Иллюстративный фотовизуал создан встроенным image_gen, не изображает реального клиента. Происхождение: `assets/campaign-life.png.json`. Фирменный знак — `assets/brand-mark.svg`, аватар 512×512 — `assets/brand-avatar.png`. Методика Unslop: Damir Sokolovsky, https://github.com/heydamir/unslop, CC BY 4.0. Проверка и документирование: Impeccable.

Проверка цветов операторов: `node tests/appearance.cjs after`, затем `python tests/logo-rendering.py` (нужны установленный Chrome и Python с Pillow). Она сравнивает реальные пиксели логотипов в обычном режиме и с принудительным затемнением Chromium. Дополнительный аргумент `--motion` сохраняет последовательности кадров первого экрана в обычном и уменьшенном движении.
